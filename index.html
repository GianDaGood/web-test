TOPIC 05

Python String Formatting

String formatting is a way of putting information such as names, ages, scores, or other values inside a sentence.

Instead of manually joining many pieces of text together, Python gives us easier ways to create clean and readable output.

🎯 What will you learn?

  • What string formatting means
  • How to use f-strings
  • How to put variables inside a sentence
  • How to create cleaner program output
  • How formatting makes programs easier to read

💻 Example 

name = "Gian"
age = 20

print(f"My name is {name}.")
print(f"I am {age} years old.")

🔍 Explanation

name = "Gian" creates a variable called name. The value stored inside it is the word Gian.

age = 20 creates another variable called age. Its value is the number 20.

Notice the letter f before the quotation marks in the print statement.

The f tells Python that we want to use an f-string.

Inside an f-string, we can put a variable inside curly brackets like this: {name}

Python will replace {name} with the actual value stored in the variable.

📌 Output 

My name is Gian.
I am 20 years old.

🧠 Simple way to remember

Think of an f-string as a sentence with blank spaces.

For example:

"My name is ______."

The variable gives Python the value that should be placed in the blank.

So if name = "Gian", the result becomes:

My name is Gian.

TOPIC 06

String Access & Slicing

A string is simply a collection of characters. Characters can be letters, numbers, spaces, or symbols.

Python allows us to access a specific character inside a string by using its index.

🎯 What will you learn?

  • What a string is
  • What an index means
  • How Python counts characters
  • How to access individual characters
  • How string slicing works

💻 Example 

word = "PYTHON"

print(word[0])
print(word[1])
print(word[-1])

🔍 Understanding the Index

One important thing to remember is that Python starts counting at 0, not 1.

For the word:

PYTHON

The positions are:

P → index 0
Y → index 1
T → index 2
H → index 3
O → index 4
N → index 5

📌 Accessing a Character 

word = "PYTHON"

print(word[0])

The result is: 

P

Why? Because P is located at index 0.

🔄 Negative Index 

word = "PYTHON"

print(word[-1])

The result is: 

N

Negative indexes allow us to count from the end of the string.

-1 means the last character.

Therefore: word[-1] gives us N.

✂️ String Slicing

Slicing means taking only a portion of a string. 

word = "PYTHON"

print(word[0:2])

The result is: 

PY

In word[0:2], the starting index is 0.

The ending index is 2.

The important rule is: the starting index is included, but the ending index is not included.

So Python takes index 0 and index 1, but stops before index 2.

🧠 Easy way to remember

Think of slicing like this:

[START : STOP]

START = where Python begins.

STOP = where Python stops, but that position is not included.

TOPIC 07

Arithmetic Operators

Arithmetic operators are symbols used in Python to perform mathematical calculations.

If you need to add, subtract, multiply, divide, or find a remainder, you will use arithmetic operators.

🎯 What will you learn?

  • Addition
  • Subtraction
  • Multiplication
  • Division
  • Floor division
  • Remainder
  • Exponent

📚 Arithmetic Operators 

+    Addition
-    Subtraction
*    Multiplication
/    Division
//   Floor Division
%    Remainder
**   Exponent

💻 Example 

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

🔍 Explanation

a = 10 means that the variable a contains the number 10.

b = 3 means that the variable b contains the number 3.

When we write a + b, Python adds 10 and 3.

The answer is 13.

➕ Addition 

10 + 3

Result: 

13

The + operator is used to add numbers.

➖ Subtraction 

10 - 3

Result: 

7

The - operator subtracts the second number from the first number.

✖️ Multiplication 

10 * 3

Result: 

30

The * operator multiplies numbers.

➗ Division 

10 / 3

Result: 

3.3333333333333335

The / operator performs normal division. The result can contain decimal numbers.

🧮 Remainder 

10 % 3

Result: 

1

The % operator gives the remainder after division.

10 divided by 3 is 3 with a remainder of 1.

Therefore: 10 % 3 = 1

🧠 Easy way to remember

+ → Add

- → Subtract

* → Multiply

/ → Divide

% → Get the remainder

// → Floor division

** → Power / exponent
