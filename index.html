TOPIC 05

Python String Formatting

String formatting is used when we want to combine text with information stored inside variables.

For example, imagine that our program needs to display a student's name and age. Instead of creating several separate pieces of text, we can use string formatting to place the values directly inside our sentence.

🎯 What will you learn?

  • What string formatting means
  • How f-strings work
  • How to put variables inside text
  • How to create clean program output

💻 Example

name = "Gian"
age = 20

print(f"My name is {name}.")
print(f"I am {age} years old.")

🔍 Explanation

name = "Gian" creates a variable named name and stores the text "Gian" inside it.

age = 20 creates another variable named age and stores the number 20.

The letter f before the quotation marks tells Python that this is an f-string.

Inside an f-string, we can put a variable inside curly brackets, such as {name}.

Python then replaces {name} with the actual value stored in the variable.

📌 Output

My name is Gian.
I am 20 years old.

🧠 Simple way to understand it

Think of an f-string as a sentence with a blank space.

For example: "My name is ______."

The variable supplies the information that goes into that blank space.

If name = "Gian", Python changes the blank into Gian.

TOPIC 06

String Access & Slicing

A string is a collection of characters. Characters can be letters, numbers, spaces, or symbols.

Python allows us to access individual characters from a string by using an index.

🎯 What will you learn?

  • What an index is
  • How Python counts characters
  • How to access a specific character
  • How negative indexes work
  • How string slicing works

💻 Example

word = "PYTHON"

print(word[0])
print(word[1])
print(word[-1])

🔍 Understanding Indexes

Python starts counting at 0, not 1.

For the word PYTHON:

P → index 0
Y → index 1
T → index 2
H → index 3
O → index 4
N → index 5

📌 Accessing a character

word = "PYTHON"

print(word[0])

The output is: 

P

This happens because the letter P is located at index 0.

🔄 Negative Index

word = "PYTHON"

print(word[-1])

The output is: 

N

Negative indexes count from the end of the string.

-1 means the last character.

Therefore, word[-1] gives us the letter N.

✂️ String Slicing

Slicing means getting only a part of a string. 

word = "PYTHON"

print(word[0:2])

The output is: 

PY

The first number is the starting index.

The second number is where Python stops.

The starting index is included, but the ending index is not included.

Therefore, word[0:2] gets index 0 and index 1, giving us PY.

TOPIC 07

Arithmetic Operators

Arithmetic operators are symbols that Python uses to perform mathematical calculations.

We use them whenever our program needs to add, subtract, multiply, divide, or perform other mathematical operations.

🎯 What will you learn?

  • Addition
  • Subtraction
  • Multiplication
  • Division
  • Floor division
  • Remainder
  • Exponent

📚 Arithmetic Operators

+    Addition
-    Subtraction
*    Multiplication
/    Division
//   Floor Division
%    Remainder
**   Exponent

💻 Example

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

🔍 Explanation

a = 10 means the variable a contains the number 10.

b = 3 means the variable b contains the number 3.

When we write a + b, Python adds 10 and 3, giving us 13.

➕ Addition

10 + 3

Result: 

13

The + operator adds two numbers.

➖ Subtraction

10 - 3

Result: 

7

The - operator subtracts the second number from the first.

✖️ Multiplication

10 * 3

Result: 

30

The * operator multiplies two numbers.

➗ Division

10 / 3

Result: 

3.3333333333333335

The / operator performs normal division.

🧮 Remainder

10 % 3

Result: 

1

The % operator gives the remainder after division.

10 divided by 3 gives 3 with a remainder of 1.

Therefore: 10 % 3 = 1

🧠 Easy way to remember

+ → Add

- → Subtract

* → Multiply

/ → Divide

% → Get the remainder

// → Floor division

** → Power / exponent
