TOPIC 05

Python String Formatting

String formatting is used when we want to combine text with variables or values to create a complete message.

🎯 What is String Formatting?

Normally, a string contains only text. But in programming, we often need to display information stored inside variables. String formatting allows us to put those values directly inside a message.

💻 Example

name = "Gian"
age = 20

print(f"My name is {name}.")
print(f"I am {age} years old.")

🔍 Explanation

name = "Gian" creates a variable called name. The value stored inside it is the text "Gian".

age = 20 creates another variable called age and stores the number 20.

Notice the letter f before the quotation marks. This tells Python that we are using an f-string.

Anything placed inside { } can be replaced by the value of a variable.

📌 Output

My name is Gian.
I am 20 years old.

🧠 Another Example

product = "Laptop"
price = 35000

print(f"The {product} costs ₱{price}.")

Here, Python takes the values of product and price and puts them into the sentence.

📌 Output

The Laptop costs ₱35000.
TOPIC 06

String Access & Slicing

A string is made up of individual characters. Python allows us to access specific characters by using their index.

🔢 Understanding Indexes

Python starts counting characters from 0, not 1. 

word = "PYTHON"

P = 0
Y = 1
T = 2
H = 3
O = 4
N = 5

💻 Accessing a Character

word = "PYTHON"

print(word[0])
print(word[1])
print(word[2])

🔍 Explanation

word[0] means: "Give me the character at index 0." The answer is P.

word[1] gives us Y.

word[2] gives us T.

📌 Output

P
Y
T

⬅️ Negative Indexing

Python also allows us to count from the end of a string. We use negative numbers for this. 

word = "PYTHON"

print(word[-1])
print(word[-2])

-1 means the last character.

-2 means the second-to-last character.

📌 Output

N
O

✂️ String Slicing

Slicing allows us to get a portion of a string instead of getting only one character. 

word = "PYTHON"

print(word[0:2])

The first number is the starting index. The second number is the ending index. The starting index is included, but the ending index is not included.

📌 Output

PY

💡 Remember

When you see: word[0:2]

Start at index 0 → P

Stop before index 2.

Therefore, the result is PY.

TOPIC 07

Arithmetic Operators

Arithmetic operators are symbols used in Python to perform mathematical calculations.

📚 Main Arithmetic Operators

+   Addition
-   Subtraction
*   Multiplication
/   Division
//  Floor Division
%   Modulus
**  Exponent

➕ Addition

a = 10
b = 3

print(a + b)

Python adds 10 and 3. 

13

➖ Subtraction

a = 10
b = 3

print(a - b)

Python subtracts 3 from 10. 

7

✖️ Multiplication

a = 10
b = 3

print(a * b)

The * operator multiplies the two values. 

30

➗ Division

a = 10
b = 3

print(a / b)

The / operator performs normal division. 

3.3333333333333335

🔢 Floor Division

print(10 // 3)

Floor division removes the decimal part of the result by rounding down to the nearest whole number. 

3

🟰 Modulus / Remainder

print(10 % 3)

The % operator gives us the remainder after division.

10 divided by 3 gives us 3 with a remainder of 1.

Therefore:

10 % 3 = 1

⚡ Exponent

print(2 ** 3)

The ** operator is used for powers. This means 2 raised to the power of 3. 

8

🧠 Complete Example

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)

📌 Important Difference

/ gives normal division and can produce a decimal.

// performs floor division.

% gives the remainder.

** calculates a power.
