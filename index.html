TOPIC 05

Python String Formatting

String formatting allows us to combine text with variables and values to create useful messages.

🎯 What will you learn?

  • What string formatting means
  • How to use f-strings
  • How to insert variables into text
  • How to create formatted output

💻 Example

name = "Gian"
age = 20

print(f"My name is {name}.")
print(f"I am {age} years old.")

🔍 Explanation

name = "Gian"
We create a variable named name and store the text "Gian" inside it.

age = 20
We create an age variable and store the number 20.

The letter f before the quotation marks allows us to insert variables inside { }.

📌 Output

My name is Gian.
I am 20 years old.
TOPIC 06

String Access & Slicing

Strings are made up of individual characters. Python allows us to access specific characters using indexes.

💻 Example

word = "PYTHON"

print(word[0])
print(word[1])
print(word[-1])

🔍 Explanation

Python starts counting indexes at 0.

P = index 0
Y = index 1
T = index 2

Using -1 means the last character.

✂️ Slicing

word = "PYTHON"

print(word[0:2])

The result is PY. The starting index is included, but the ending index is not.

TOPIC 07

Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations in Python.

📚 Operators

+   Addition
-   Subtraction
*   Multiplication
/   Division
//  Floor Division
%   Remainder
**  Exponent

💻 Example

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

🔍 Explanation

+ adds two numbers.

- subtracts numbers.

* multiplies numbers.

/ performs division.

% gives the remainder.
