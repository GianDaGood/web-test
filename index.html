TOPIC 05

Python String Formatting

String formatting is used when we want to combine text with information stored inside variables.

For example, if we have a student's name and age, we can put those values directly into a sentence.

🎯 What will you learn?

  • What string formatting means
  • How f-strings work
  • How to put variables inside text
  • How to create clean program output

💻 Example

name = "Gian"
age = 20

print(f"My name is {name}.")
print(f"I am {age} years old.")

🔍 Explanation

name = "Gian" creates a variable called name and stores "Gian".

age = 20 creates a variable called age and stores the number 20.

The letter f before the quotation marks means that we are using an f-string.

An f-string allows us to place variables inside curly brackets, such as {name}.

Python replaces the curly brackets with the actual value stored in the variable.

📌 Output

My name is Gian.
I am 20 years old.

🧠 Simple way to understand it

Think of an f-string as a sentence with a blank space.

"My name is ______."

If the variable contains "Gian", Python puts "Gian" into that blank.

So the final sentence becomes: My name is Gian.

TOPIC 06

String Access & Slicing

A string is a collection of characters. Characters can be letters, numbers, spaces, or symbols.

Python allows us to access individual characters using their index.

🎯 What will you learn?

  • What an index is
  • How Python counts characters
  • How to access a specific character
  • How negative indexes work
  • How string slicing works

💻 Example

word = "PYTHON"

print(word[0])
print(word[1])
print(word[-1])

🔍 Understanding Indexes

Python starts counting at 0, not 1.

For the word PYTHON:

P → index 0
Y → index 1
T → index 2
H → index 3
O → index 4
N → index 5

📌 Accessing a Character

word = "PYTHON"

print(word[0])

The output is: 

P

This happens because P is located at index 0.

🔄 Negative Index

word = "PYTHON"

print(word[-1])

The output is: 

N

Negative indexes allow us to count from the end of a string.

-1 means the last character.

Therefore, word[-1] gives us N.

✂️ String Slicing

Slicing means getting only a part of a string. 

word = "PYTHON"

print(word[0:2])

The output is: 

PY

The first number is the starting index.

The second number is where Python stops.

The starting index is included, but the ending index is not included.

Therefore, word[0:2] gets index 0 and index 1, giving us PY.

TOPIC 07

Arithmetic Operators

Arithmetic operators are symbols used by Python to perform mathematical calculations.

They allow our programs to add, subtract, multiply, divide, and perform other mathematical operations.

🎯 What will you learn?

  • Addition
  • Subtraction
  • Multiplication
  • Division
  • Floor division
  • Remainder
  • Exponent

📚 Arithmetic Operators

+    Addition
-    Subtraction
*    Multiplication
/    Division
//   Floor Division
%    Remainder
**   Exponent

💻 Example

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

🔍 Explanation

a = 10 means that the variable a contains the number 10.

b = 3 means that the variable b contains the number 3.

When we write a + b, Python adds 10 and 3, resulting in 13.

➕ Addition

10 + 3

Result: 

13

The + operator is used to add numbers.

➖ Subtraction

10 - 3

Result: 

7

The - operator subtracts the second number from the first.

✖️ Multiplication

10 * 3

Result: 

30

The * operator multiplies numbers.

➗ Division

10 / 3

Result: 

3.3333333333333335

The / operator performs normal division.

🧮 Remainder

10 % 3

Result: 

1

The % operator gives the remainder after division.

10 divided by 3 gives 3 with a remainder of 1.

Therefore: 10 % 3 = 1

🧠 Easy way to remember

+ → Add

- → Subtract

* → Multiply

/ → Divide

% → Remainder

// → Floor division

** → Power / exponent
